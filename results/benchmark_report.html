Sequence/substitution-matrix transfer strategy (CS-3): no substitution matrix is used — scoring is uniform match/mismatch/gap scalars baked in at compile time (DNA alignment convention this whole project uses; ACGT only). Sequences: one PE per character of sequence A (one distinct int32 per PE via a single memcpy_h2d, row-major onto the PE line); sequence B is broadcast identically to every PE's local memory (np.tile + one memcpy_h2d), so each PE walks all of B locally with zero fabric traffic during compute. One compile serves the entire sweep, since every sequence in the dataset is the same 1000bp — sweeping n only changes how many pairs run through the same fixed-shape kernel. GPU: per-pair H2D/D2H of the two sequences and the resulting H/TB matrices; kernel_ms is pure on-device compute time, tracked per-call in this codebase already.
